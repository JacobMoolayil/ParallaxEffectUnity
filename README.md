# ParallaxEffect
With this script, you can create a parallax effect in the background of your 2D game.

## 📌 How to Use  

Follow these steps to implement the parallax effect in your 2D game:  

### 1️⃣ **Prepare Sprites for Looping**  
- Select three identical sprites that will be used for seamless looping.  
- Arrange them in a row to create a continuous scrolling effect.  

### 2️⃣ **Group the Sprites**  
- Create an empty GameObject to act as a parent.  
- Place all three sprites inside this parent object.  

### 3️⃣ **Attach the Script**  
- Add the provided script to the parent GameObject (the group of sprites).  

### 4️⃣ **Configure Variables**  
- Open the **Inspector** tab.  
- Assign the necessary references (e.g., camera reference, parallax speed, length of sprite).  
- Adjust the values to achieve the desired parallax effect.  

Now, when you run your game, the background will smoothly scroll, creating a dynamic parallax effect! 🎮✨
